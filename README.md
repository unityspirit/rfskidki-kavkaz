# 🏷️ ХабСкидок.рф (Край Скидок)

> **Инновационный агрегатор скидок и система лояльности по QR-кодам с интерактивной Яндекс Картой, моментальной выдачей купонов за честные отзывы и полноценной панелью управления.**

---

## 🌟 Концепция проекта

1. **Переход по QR-коду:** Гость заведения (ресторана, кофейни, автомойки, барбершопа, спа-комплекса, фитнес-клуба) сканирует фирменный QR-код на тейбл-тенте, столике или наклейке у кассы.
2. **Отзыв в 1 клик:** Гость ставит оценку звёздами (1–5), выбирает эмодзи-теги впечатлений и пишет пару тёплых слов или замечаний.
3. **Моментальная скидка:** Система запускает праздничное конфетти 🎉 и выдает уникальный цифровой купон со штрихкодом и QR-кодом (например, `-25% НА ВСЁ МЕНЮ` или `2-й КОФЕ В ПОДАРОК`), который гость сразу показывает официанту или кассиру.
4. **Интерактивная Яндекс Карта:** Возможность выбрать скидку в **любом заведении поблизости**! Встроенная геолокация определяет местоположение гостя, вычисляет точное расстояние (в метрах и километрах) и фильтрует заведения в радиусе 5, 15, 30 км.
5. **Отдельная панель управления (Админка):**
   - Добавление, редактирование и удаление заведений на Яндекс Карте.
   - **Управление администраторами:** Назначение коллег администраторами и модераторами с разграничением прав (`Главный администратор`, `Модератор отзывов`, `Менеджер партнеров`).
   - Модерация отзывов клиентов.
   - Встроенный генератор тейбл-тентов с QR-кодами для печати на столы заведений.
   - Кассовый терминал для проверки и погашения скидок.

## 🚀 Быстрый запуск

### Способ 1: В один клик (Windows)
Просто дважды кликните по файлу **`start.bat`**.

### Способ 2: Через командную строку / терминал
```bash
# В папке проекта
node server.js
```

Сервер запустится мгновенно без необходимости компиляции внешних библиотек (использует встроенные современные модули Node.js 20+ / 24+).

- 🌐 **Клиентский сайт:** [http://localhost:3000](http://localhost:3000)
- ⚙️ **Панель управления (Админка):** [http://localhost:3000/admin.html](http://localhost:3000/admin.html)

## 👥 Назначение администраторов («Кого назначим админом»)

В панели управления перейдите на вкладку **«Администраторы & Роли»**:
1. Нажмите кнопку **`+ Назначить нового администратора`**.
2. Введите:
   - **Имя и фамилию** сотрудника
   - **Email** (будет использоваться как логин)
   - **Пароль**
   - **Телефон**
   - **Роль**:
     - 👑 **Главный администратор (Super Admin):** полный контроль сайта и назначение других сотрудников.
     - 🛡️ **Модератор отзывов:** одобрение/отклонение отзывов, кассовое погашение купонов.
     - 💼 **Менеджер партнеров:** подключение новых заведений и настройка акций.
3. Новый администратор может сразу входить в систему со своими данными. При необходимости Главный админ может в любой момент **отозвать доступ**.

2. Система мгновенно сформирует адаптивный макет тейбл-тента с фирменным стилем, заголовком акции и рабочим QR-кодом.

## 🛠️ Архитектура и технологии

- **Бэкенд:** Node.js (чистый, легковесный, высокопроизводительный HTTP REST API с защитой от Directory Traversal, сессиями, соленым хешированием паролей через `crypto.pbkdf2Sync`).
- **База данных:** Файловая персистентная база `data/db.json` с атомарной записью (через временный файл + rename для исключения повреждения данных).
- **Картография:** Интерактивное **Яндекс Карты API v2.1** с кластеризацией, кастомными гео-метками, балунами заведений, определением геолокации HTML5 Geolocation и расчетом расстояний по формуле гаверсинусов.
- **Генерация QR-кодов:** Автономная библиотека `qrcode.min.js` (генерация векторных и растровых QR без зависимости от сторонних серверов).
- **Анимации:** `canvas-confetti` для праздничного эффекта при выигрыше скидки.
- **Интерфейс:** Современный адаптивный UI с поддержкой смартфонов, планшетов и ПК.
